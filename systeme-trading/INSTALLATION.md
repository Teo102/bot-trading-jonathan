# Installation du projet dans Claude Code

1. Décompresser `systeme-trading.zip` à l'endroit voulu (par exemple `~/systeme-trading`).
2. Ouvrir un terminal dans ce dossier, puis lancer `claude`.
3. Vérification : demander « Quels skills sont disponibles ? ». Les 14 skills du système doivent apparaître, dont cerveau-trading 2.1.
4. Première mission : écrire « VALIDER STRAT-20261031-01 ». Le cerveau ouvre la chaîne V1 et exécute la procédure de `strategies/STRAT-20261031-01/`.

Prérequis sur la machine : Python 3.11 ou plus récent, accès Internet. freqtrade s'installe pendant la mission (pip ou Docker).

Les skills de ce projet sont la référence pour Claude Code. Ceux de claude.ai se mettent à jour séparément (Paramètres > Fonctionnalités > Skills), avec les mêmes zips.
